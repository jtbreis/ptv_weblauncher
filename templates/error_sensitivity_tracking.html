Error Sensitivity Tracking
Sweep stereomatching error thresholds on a high-threshold STM file (rays_out_cpp.h5 with loose maxdistance). For each error ceiling, filter particles with error ≤ threshold in-memory, run graph-based 4-frame tracking in parallel batches, and write tracks_error_*.h5part files so you can compare how tracking responds to stereomatching error. The input rays_out_cpp.h5 is read-only and is never rewritten.
Data location
Input must include stereomatching error in xyze[3].
Filtering — error threshold sweep

Each value in the sweep filters the STM particle pool (error ≤ threshold), then runs a full independent tracking pass. There is no shared graph between thresholds.

0 = use STM maxdistance attribute.
Graph linking — path enumeration

Same linking settings for every threshold in the sweep. Controls how candidate paths are built after the STM filter is applied.

Keep only 4-frame paths found in both forward and backward enumeration.

Outputs

Writes under each run directory, one tracks file per error threshold: tracks_error_0.0500.h5part, … and error_sensitivity_summary.json. The input STM file is not modified.
