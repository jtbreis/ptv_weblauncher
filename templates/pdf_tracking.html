PDF Relaxed Tracking
Start from a high-threshold STM file (rays_out_cpp.h5 with loose maxdistance). Graph-track only low-error particles to build a velocity PDF (e.g. vx). Then iteratively relax the error ceiling: each round re-runs graph linking on still-unmatched detections only, and accepts new tracks whose segment velocities fall inside the PDF. Matched particles are reserved and never re-used.
Data location
Input must include stereomatching error in xyze[3] (standard STM output).
